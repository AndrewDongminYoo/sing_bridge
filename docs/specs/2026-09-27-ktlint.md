# Kotlin lint adoption

Add pinned ktlint to the existing Trunk gate in a separate PR stacked on local import.
The approved scope is Kotlin source and Gradle Kotlin scripts, EditorConfig, Trunk configuration, and related guidance.
No application behavior or dependencies change.

## Acceptance

- Use managed Java and ktlint on macOS locally and Linux CI.
- Report both formatting differences and non-fixable Kotlin rule violations.
- Keep Compose function names and the existing trailing-comma convention.
- Format only the tracked Kotlin files identified in the plan.
- Follow the [current project workflow](../../AGENTS.md#workflow): automatic pre-commit formatting is enabled; stage explicit paths and review the formatted index before pushing.
- Pass the scoped lint check and shared tests; use existing hosted native build gates.

## Limits

This change does not add static analysis beyond ktlint or alter generated files.
It requires no visual approval because it does not change rendered UI.
