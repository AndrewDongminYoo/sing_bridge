# SingBridge Baseline Implementation Plan

**Goal:** Initialize a local Git repository and a working offline KMP song-practice baseline.

**Architecture:** Common Kotlin owns lyric timing and practice state.
Compose provides one shared screen.
Android Media3 and iOS AVPlayer provide actual playback.

**Tech Stack:** Kotlin, Compose Multiplatform, Android Gradle Plugin, Gradle, SwiftUI, XcodeGen.

**Spec:** `docs/specs/2026-09-27-baseline.md`.

## Execution

The root agent executes sequentially in the main workspace under the operator's implementation request.
Do not create remote repositories, push, or commit without a request.

## Global constraints

- Android API 26 or later and iOS 17.2 or later.
- Development bundle ID: `io.github.andrewdongminyoo.singbridge`.
- Original demonstration content only.
- No simulated playback clock.
- No backend or automatic transliteration.

## Review focus

- Exact line end: move to the next line or clear the highlight.
- Gaps: do not highlight a line during silence.
- Repeat: seek to the selected start only during active playback.
- Track completion: play again from the beginning.
- App backgrounding: pause the native player.
