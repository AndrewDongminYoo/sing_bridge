# Kotlin lint adoption plan

The operator approved a separate ktlint PR while product research continues.
Use the existing workspace and stack this branch on `feat/local-song-import`.
Root owns all edits, staging, and verification.

## Steps

1. Inspect the pinned Trunk plugin and EditorConfig behavior.
2. Prove a formatting error and a non-fixable naming error fail through Trunk; correct the fixture and require success, then delete it.
3. Preview and format the explicit tracked Kotlin paths below.
4. Review the diff for behavior changes; run `trunk check --all --no-fix --filter=ktlint` and `./gradlew :shared:jvmTest`.
5. Commit configuration and formatting separately, open the stacked PR, and observe existing CI and review gates.
